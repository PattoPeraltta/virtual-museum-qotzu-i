# Uru Virtual Museum

A responsive, multi-route virtual museum documenting Lake Poopó, the Uru Indigenous Nation, and the Qotzuñi impact project.

## Routes

- `/` — scroll-led museum introduction
- `/lake-poopo` — ecological and historical context
- `/about` — Uru language, craft, leadership, and rights
- `/impact` — documentary and partner work
- `/resources` — films, photography, and research

## Development

```bash
npm install
npm run dev
npm run build
npm test
```

## Deployment

The site is a native Next.js App Router project and can be deployed directly to Vercel. The production URL is derived from Vercel's project environment automatically.
